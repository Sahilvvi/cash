SQL Query: View Recent Clicks

Run this in your Supabase SQL editor to see tracked clicks:

SELECT 
    ac.session_id,
    ac.clicked_at,
    p.email as user_email,
    s.name as store_name
FROM affiliate_clicks ac
LEFT JOIN profiles p ON p.user_id = ac.user_id
LEFT JOIN stores s ON s.id = ac.store_id
ORDER BY ac.clicked_at DESC
LIMIT 10;
